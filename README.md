### 안녕하세요, 유지인입니다 👋

***LLM을 어디까지 믿고 어디서부터 코드로 제어할지, 그 경계를 설계하는 AI Application 엔지니어***

기능을 만들기 전에 **평가 기준부터 설계합니다.** 지표가 무엇을 보증하는지 스스로 검증하고, 채택한 것과 기각한 것을 근거와 함께 기록으로 남기는 것까지를 개발의 일부로 봅니다.

- 모델이 "확인했다"고 말해도 믿지 않고, **코드가 원문과 직접 대조**하게 만듭니다
- 숫자 하나로 끝내지 않고, **어디서 새는지 나눠서** 잽니다
- 토큰은 무조건 줄이지 않고, **정확도가 포화하는 지점까지만** 씁니다
